Pasang firmware lampu meja

SPL Sports Pool Lounge · untuk ESP32-S3 · versi spl-lampu-2.3

Browser ini tidak bisa memasang firmware. Buka halaman ini di Google Chrome atau Microsoft Edge di PC/laptop (bukan HP, bukan aplikasi SPL Kasir).

1Sambungkan ESP32 ke PC

Pakai kabel USB-C yang bisa data (bukan kabel cas saja). Colok ke port bertulisan USB atau COM di board.

2Tekan tombol di bawah

Muncul jendela kecil berisi daftar perangkat. Pilih yang bertulisan USB JTAG, USB Serial, CP210x, atau CH340 (COM…), lalu Connect → Install SPL Lampu Meja → Install. Tunggu ±1 menit sampai 100%.

Halaman ini harus dibuka lewat https.

Daftar perangkat kosong? Tahan tombol BOOT di board, tekan RESET sekali, lepas BOOT, lalu tekan tombol kuning lagi. Kalau tetap kosong, ganti kabel USB.

3Sesudah 100%: atur alatnya dari HP

Alat yang sudah pernah diatur (Wi-Fi, kunci, nomor board) tidak perlu diatur ulang — pengaturannya tetap tersimpan. Cukup tekan RESET dan cek halamannya. Langkah di bawah untuk alat baru, atau kalau ingin mengubah isian.

  1. Tekan RESET sekali dan lepas. Tunggu 5 detik, lalu tahan tombol BOOT 3 detik sampai hotspot muncul. (Alat baru membuka hotspot sendiri tanpa menahan BOOT.) Jangan menahan BOOT sambil menekan RESET.
  2. Di HP, sambung ke Wi-Fi SPL-Lampu-XXXX, sandi pasanglampu.
  3. Buka http://192.168.4.1 di browser HP.
  4. Isi Wi-Fi venue + password, Kunci alat, dan Nomor board (1 atau 2). Bagian Lanjutan — server biarkan kosong.
  5. Tekan Simpan. Ulangi semua langkah untuk board kedua dengan kunci yang sama.

Kunci alat didapat dari mana?

Buka kasir.sportspoollounge.com di Chrome, masuk sebagai superadmin → Atur → Lampu meja → Buat kunci baru (satu kali saja) → Pasang kunci ini di server. Foto kuncinya, lalu ketik kunci yang sama di kedua board.

Cara memastikan sudah jalan

  • Di aplikasi kasir, Atur → Lampu meja menampilkan alat online (2).
  • Halaman alat (http://lampu-spl1.local atau IP-nya) menulis ok dan "terakhir tersambung 1 detik lalu".
  • Kalau tertulis KUNCI ALAT SALAH: ketik ulang kunci (langkah 3). ANON KEY SALAH: kosongkan bagian Lanjutan lalu Simpan.

Memasang firmware ini tidak menghapus pengaturan yang sudah diisi di alat. Lampu fisik dan kabel relay tidak berubah.
